Aplikasi Web Dashboard Keuangan berbasis **Static Web HTML/JS** yang terintegrasi secara *real-time* dengan **Google Sheets** via **Google Apps Script (GAS)** sebagai backend data.

---

## 🚀 Fitur Utama

- **Pencatatan Pemasukan & Pengeluaran:** Input data transaksi keuangan secara cepat dan terekap otomatis.
- **Integrasi Google Sheets:** Tanpa perlu database berbayar, seluruh data tersimpan aman di spreadsheet Google.
- **Floating WhatsApp Button:** Fitur komunikasi interaktif langsung ke WhatsApp pengelola/developer.
- **Kustomisasi Pengaturan (Modal Config):** Hubungkan URL Web App Apps Script dan Spreadsheets langsung via antarmuka UI tanpa edit kode internal.
- **Responsif & Modern:** Tampilan ciamik di perangkat desktop maupun HP (Mobile-friendly).
